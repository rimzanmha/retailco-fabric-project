# RetailCo Fabric Project

RetailCo 360 is an end-to-end retail analytics platform that I built on Microsoft Fabric. It takes messy sales data through a medallion lakehouse, serves it from a T-SQL star-schema warehouse and a Power BI report, adds a real-time operations dashboard, and promotes the solution from a Dev to a Test workspace with a deployment pipeline.

## Business problem and goals
1. Poor Data Quality: Duplicate orders, missing values, and inconsistent data formats.
2. No Single Source of Truth: Inconsistent sales reporting across five stores and the online channel.
3. Lack of Automation: Manual data processing and limited pipeline monitoring.
4. No Real-Time Visibility: Limited ability to monitor incoming orders as they happen.
